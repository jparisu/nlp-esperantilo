# Esperanto

Ĉi tiu sekcio traktas la Esperantan lingvon mem — ĝian historion, gramatikon,
vortprovizon kaj lernorimedojn. Ĝi estas forte orientita al la lingvistiko kaj al la
reguleco de Esperanto, por ke el ĝi eblu efektivigi regul-bazitan
NLP-bibliotekon.

La paĝoj iras de kunteksto al datumoj: la rakonto pri la lingvo, poste ĝiaj reguloj,
kaj poste la listoj, kiujn tiuj reguloj produktas. Se vi bezonas nur la lingvajn
datumojn por la biblioteko, saltu al [Gramatiko](grammar.md) kaj
[Vortprovizo](vocabulary.md).
