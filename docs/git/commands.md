## Everyday commands

Each command gets a short description, its most useful options and a small
example.

| Command | Purpose |
| --- | --- |
| `git init` | Create a repository. |
| `git clone` | Copy an existing repository. |
| `git add` | Stage changes. |
| `git commit` | Record staged changes in the history. |
| `git status` | See what changed and what is staged. |
| `git log` | Read the history. |
| `git diff` | Inspect changes. |
| `git branch` | List, create or delete branches. |
| `git checkout` | Move between branches and commits. |
| `git merge` | Integrate one branch into another. |
| `git push` | Send commits to the remote. |
| `git pull` | Bring remote commits into the local branch. |
