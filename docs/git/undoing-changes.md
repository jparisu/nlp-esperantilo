# Undoing changes

!!! note "Under construction"
    Planned contents are listed below.

Three practical ways to "go back", with a small example of each and guidance on
when to use which.

## `git restore`

Discard changes in the working directory.

## `git reset`

Move the branch pointer, or unstage changes.

## `git stash`

Temporarily set changes aside and get a clean working directory.

## Which one do I need?

A short decision guide mapping common situations to the right command.
