    Vocabulary¶

    Where Grammar gives the rules, this page gives the lists — the concrete data the library will load: the stop-words, the full affix inventory, and a starter set of common roots. The lists here are meant to be copied straight into the library's resources.

    Stop-words¶

    Stop-words are high-frequency words that carry little meaning on their own — the article, prepositions, conjunctions, pronouns, correlatives and common adverbs. An NLP pipeline usually filters them out before analysis, so that la, de, kaj and mi do not drown out the content words.

    Esperanto stop-words are easy to enumerate because most belong to the small, closed classes described in Grammar: the one article la, the personal pronouns, the 45 correlatives, and a fixed set of prepositions and conjunctions.

    The full list already exists as data

    This project ships the complete list as a machine-readable file, rendered here automatically:

    Stop-words → — 122 entries, each with its English translation, grammatical category and provenance. It is generated from resources/esperanto/vortoj.json, the same file the library will read at runtime, so the documentation and the data can never disagree.

    Roots only¶

    122 entries is a short list, and deliberately so. Esperanto builds words by adding morphemes to a root, so a list written word by word repeats itself: mi, mia, min and mian are one pronoun and three endings; esti, estas, estis, estos, estus and estu are one verb and five.

    The lexicon therefore stores roots, not forms. An entry earns its place only if it cannot be built from another entry plus a rule written down on this site. By that test 131 of the original 252 entries were dropped:

    Dropped Built from Rule
    mia, min, mian, nia, ĝin, … the pronoun mi, ni, ĝi, … Grammar § Personal pronouns
    unua, dua, deka, … the cardinal unu, du, dek, … Grammar § Numbers
    estas, havis, povus, … the infinitive esti, havi, povi Grammar § Verb system
    all 59 correlative entries five prefixes × nine endings Grammar § Correlatives
    malantaŭ, sinjorino, supren antaŭ, sinjoro, supre § Affixes below
    bv, s-ro, d-ro, k, … nothing — see § Abbreviations —

    Five roots were added in exchange, because forms were present whose root was not: bona, feliĉa, bonvoli, fraŭlo and supre.

    The list and the lemmatizer ship together

    A roots-only list is smaller and weaker on its own: token in stop_words no longer catches estas or min. It is only correct for a pipeline that normalises first — strip the endings, then look up. Filtering raw tokens against this list will let inflected stop-words through.

    A representative sample, by category:

    Category Examples
    Article la
    Prepositions al, de, en, kun, por, pri, sur, sub, tra
    Conjunctions kaj, aŭ, sed, ke, ĉar, se, nek
    Pronouns mi, vi, li, ŝi, ĝi, ni, ili, oni, si
    Common adverbs ankaŭ, ankoraŭ, jam, nur, tre, tro, plu
    Verbs esti, havi, povi — infinitives only

    The correlatives are stop-words too, all 45 of them, but they are not in the file: they are generated by the table.

    The rest — why each word qualifies and where the entries come from — lives with the generated list; this page only summarises.

    Affixes¶

    The affixes are the most important vocabulary data for a lemmatizer: they let it decompose a derived word back to its root. Below is the full inventory introduced in Grammar § Affixes, grouped by role and ready to encode.

    Grammatical endings (inflectional)¶

    These are stripped first, in reverse order, to reach the stem:

    Group Endings
    Word class -o (noun), -a (adjective), -e (adverb), -i (verb inf.)
    Number / case -j (plural), -n (accusative), -jn (both)
    Verb tense / mood -as, -is, -os, -us, -u, -i

    Derivational prefixes¶

    Prefix Role Example
    mal- opposite malbona (bad)
    ge- both sexes gepatroj (parents)
    ek- sudden / inceptive ekiri (to set off)
    re- again / back reveni (to return)
    dis- scattering disdoni (to distribute)
    mis- wrongly miskompreni (to misunderstand)
    bo- in-law bopatro (father-in-law)
    pra- primordial / great- praavo (great-grandfather)

    Derivational suffixes¶

    Suffix Role Example
    -in- female patrino (mother)
    -ist- professional instruisto (teacher)
    -ej- place lernejo (school)
    -il- tool tranĉilo (knife)
    -ar- collection arbaro (forest)
    -et- diminutive dometo (cottage)
    -eg- augmentative domego (mansion)
    -ul- person junulo (youth)
    -an- member urbano (citizen)
    -ec- abstract quality boneco (goodness)
    -ig- to make / cause grandigi (to enlarge)
    -iĝ- to become ruĝiĝi (to blush)
    -ind- worthy of aminda (lovable)
    -em- inclined to laborema (hardworking)
    -aĉ- pejorative domaĉo (hovel)

    Order of stripping for lemmatization

    To recover the root of a word like malsanulejojn, peel from the outside in: -n → -j → -o (endings), then -ej-, -ul- (suffixes), then the mal- prefix, leaving san- ("health"). Each step is a table lookup.

    Abbreviations¶

    Abbreviations are the one group the roots-only rule cannot regenerate. s-ro is not sinjoro plus an ending — no amount of stripping produces it — so removing it from the lexicon means it has to be written down here instead. A pipeline that wants to expand them needs this table as data:

    Abbreviation Expansion Meaning
    bv bonvolu please
    d-ro doktoro Dr.
    ekz ekzemple e.g., for example
    f-no fraŭlino Miss
    k kaj and
    s-no sinjorino Mrs.
    s-ro sinjoro Mr.

    The pattern behind most of them is first letter, hyphen, last syllable: s-ro ← s(injo)ro. It is a convention, not a rule, and the variants are real — s-ino is as common as s-no. Treat the table as closed and extend it by hand.

    Most common roots¶

    A lemmatizer also benefits from a list of known roots, both to validate a decomposition and to catch the frequent words that appear everywhere. A starter set of very common roots, by class:

    hav- to have vol- to want

    ir- to go sci- to know (facts)

    don- to give pren- to take
    leg- to read skrib- to write
    manĝ- to eat labor- to work
    am- to love help- to help
    Root Meaning Root Meaning
    hom- human mond- world

    This is only a seed. A production list is best derived by frequency from a corpus; the point here is that roots, like everything else in Esperanto, are a finite list the library can hold in a file.

    Format¶

    All of these lists are stored the same way, as JSON files under resources/, so that a single source of truth can feed both the code (at runtime) and the documentation (at build time, via docs/hooks/word_lists.py). Field names are in Esperanto, matching the file names; translatable fields are objects keyed by locale:

    {
  "id": "ignorindaj-vortoj",          // also the URL of the generated page
  "titolo": { "eo": "Ignorindaj vortoj", "en": "Stop-words" },
  "lingvo": "eo",
  "tradukoj": ["en"],                 // locales present in "traduko"
  "kategorioj": {                     // grammatical categories used below
    "prepozicio": { "en": "Preposition" }
  },
  "vortoj": [
    {
      "vorto": "kun",                 // the word, lowercase
      "kategorio": "prepozicio",      // a key of "kategorioj"
      "traduko": { "en": ["with"] },
      "fontoj": ["stopwords-iso"]     // provenance, optional
    }
  ]
}

    The documentation build only requires id, titolo and vortoj, but tests/test_resources.py is stricter: id must equal the file name, and every vorto must be lowercase, unique, carry a traduko and use a kategorio declared in kategorioj. Files are UTF-8 and keep the real diacritics (ĉ ĝ ĥ ĵ ŝ ŭ), never the x-system. A malformed edit therefore fails in CI rather than in a documentation build. The full schema is documented in resources/README.md.

    Using a list from the library is then a two-liner:

    import json
from pathlib import Path

data = json.loads(Path("resources/esperanto/vortoj.json").read_text(encoding="utf-8"))
stop_words = {entry["vorto"] for entry in data["vortoj"]}
