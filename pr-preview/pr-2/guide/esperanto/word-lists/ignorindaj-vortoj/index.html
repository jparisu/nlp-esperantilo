    Stop-words¶

    The high-frequency, low-content words that a text-processing pipeline usually filters out before analysing a text.

    English only

    These pages are generated from the data files, which carry English translations only. They are not translated into the other languages of this site.

    About this list

    250 entries, selected from resources/vortoj.json by the filter {"ignorinda": true}. The page and the data cannot drift apart: the table below is the file.

    Download the whole lexicon: vortoj.json
